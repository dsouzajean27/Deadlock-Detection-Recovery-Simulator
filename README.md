# Deadlock Detection and Recovery Simulator

## Overview
This project is a mini Operating Systems simulator implementing:

- Banker's Algorithm
- Deadlock Detection
- Recovery Strategies
- Resource Allocation Graph (RAG)

The simulator visually demonstrates safe states, unsafe states, deadlock cycles, and recovery mechanisms.

---

## Features

- Dynamic Allocation, Max, Need matrices
- Banker's Algorithm implementation
- Safe sequence generation
- Deadlock detection
- Recovery simulation
- Resource Allocation Graph visualization
- Interactive UI using Cytoscape.js
